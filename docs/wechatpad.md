# WechatPad 与微信接入

通过可选的 WechatPad 服务，把微信会话接到 DSH 中已有的主 Bot 或 Bot 群。

## 关联会话与回传附件

在主 Bot 或 Bot 群的右侧详情面板中打开设置，可关联微信私聊或 Pad 微信群。WechatPad 0.1.10 引入了此入口。可选择 WechatPad 或微信机器人连接，再选择已发现的微信用户或微信群；用户发来消息后即可选择，无需查 ID。微信群候选和已关联列表显示群名及群 ID，方便辨认同名群；暂时取不到名称时标为“未获取到群名”。微信设置的“会话”页仅显示关联汇总。普通 Bot 不能关联。绑定沿用目标的当前会话段，群成员可见文字带名字回传微信；不外发隐藏 Bot 回合或推理，不启用上游 IM 模块。仍遵守 WechatPad 访问控制；授权、密钥和交互卡在 DSH 处理。详见 [能力比较与关联设计](plans/2026-11-05-upstream-and-wechatpad.md)。

微信发起的主 Bot 回合可用 `wechatpad_return_file` 或宿主 `present` 回传音频、图片和文件，附件只投递给发起该回合的原连接/聊天；生成与登记不等于送达。扫码机器人音频走文件通道，Pad 支持的短音频走原生语音。群附件须由成员在正式发言中显式附上文件链接。微信入站消息以文案和图片缩略图为主，附件路径、格式和大小默认收在可展开详情中；模型仍收到原始信息。

## 入站消息、排队和打断

微信私聊关联沿用微信插件的“新消息处理方式”：打断时先取消当前主 Bot 私聊轮次，再提交新消息；Bot 群仍排队，不停止全群成员。原生输入框上方显示 DSH 实际待处理队列，支持立即介入或移除，仅展示用户来源消息。微信机器人输入状态根据实际私聊工作续期，结束、停止或解绑后清理；WechatPad 协议不支持该状态。
